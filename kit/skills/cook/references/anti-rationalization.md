# Anti-Rationalization

The excuses an agent reaches for when it wants to skip the plan step, and why
each one is wrong. Read when you notice yourself about to write code before a
plan exists and has been reviewed.

| Thought | Reality |
|---------|---------|
| "This is too simple to plan" | Simple tasks have hidden complexity. Plan takes 30 seconds. |
| "I already know how to do this" | Knowing ≠ planning. Write it down. |
| "Let me just start coding" | Undisciplined action wastes tokens. Plan first. |
| "The user wants speed" | Fastest path = plan → implement → done. Not: implement → debug → rewrite. |
| "I'll plan as I go" | That's not planning, that's hoping. |
| "Just this once" | Every skip is "just this once." No exceptions. |

The only legitimate exits from the plan gate are the ones `SKILL.md` names:
the user's explicit "just code it" / "skip planning", and `code` mode, where
the accepted plan is the reviewed plan.
